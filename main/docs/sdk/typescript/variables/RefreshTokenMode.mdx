*The refresh-token variant used when `useRefreshTokens: true`.

- `RefreshTokenMode.Offline` (default): rotating offline refresh tokens.
- `RefreshTokenMode.Online`: non-rotating Online Refresh Tokens (ORTs).*

type RefreshTokenMode = object
