<Callout icon="triangle-exclamation" color="#F59E0B" iconType="regular">
  Total sustained throughput to both the Authentication API and My Account API in a Private Cloud environment is generally supported up to 500 RPS. Certain workloads — heavy combined usage of Authentication and Management APIs, or flows like ROPG — may cause degraded performance at lower RPS.
</Callout>

<Info>
  Private Cloud rate limits apply to both production and non-production (Dev/Staging) environments unless otherwise noted.
</Info>
