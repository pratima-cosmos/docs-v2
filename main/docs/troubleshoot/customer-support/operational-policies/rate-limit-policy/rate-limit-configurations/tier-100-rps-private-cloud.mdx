<Callout icon="triangle-exclamation" color="#F59E0B" iconType="regular">
  Total sustained throughput to both the Authentication API and My Account API in a Private Cloud environment is generally supported up to 500 RPS. Certain workloads may cause degraded performance at lower RPS.
</Callout>
