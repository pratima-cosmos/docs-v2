## `rps schema`

```json
{
  "api": "Authentication API",
  "global_limit": { "burst": 100, "sustained": "100/second" },
  "endpoint_override": {
    "path": "/userinfo",
    "method": "GET",
    "burst": 10,
    "sustained": "5/minute",
    "limit_key": "unique user ID"
  }
}
```
