<Tip>
The interactive "Try it" panel above only accepts one field at a time, so pasting a full JSON object (e.g. one copied from a [GET user](/docs/api/management/v2/users/get-users-by-id) response) isn't practical there. Use `curl` for that instead:

```bash
curl --request PATCH \
  --url 'https://{yourDomain}/api/v2/users/{id}' \
  --header 'Authorization: Bearer {yourMgmtApiAccessToken}' \
  --header 'Content-Type: application/json' \
  --data @user-update.json
```
