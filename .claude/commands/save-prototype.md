# Save Prototype State

Saves the current state of all action-triggers-prototype files to the option-1 saved-work folder and updates memory.

## Steps

1. Copy the following files to `~/Desktop/Docs_Project/Custom explorers/option-1/`:
   - `~/docs-v2/main/config/navigation/actions-triggers.json`
   - `~/docs-v2/main/config/nav.en.json`
   - `~/docs-v2/main/config/navigation/customize.json`
   - `~/docs-v2/main/ui/css/styles.css`

2. Run these copy commands:
```bash
cp ~/docs-v2/main/config/navigation/actions-triggers.json "/Users/pratima.rajput/Desktop/Docs_Project/Custom explorers/option-1/actions-triggers.json"
cp ~/docs-v2/main/config/nav.en.json "/Users/pratima.rajput/Desktop/Docs_Project/Custom explorers/option-1/nav.en.json"
cp ~/docs-v2/main/config/navigation/customize.json "/Users/pratima.rajput/Desktop/Docs_Project/Custom explorers/option-1/customize.json"
cp ~/docs-v2/main/ui/css/styles.css "/Users/pratima.rajput/Desktop/Docs_Project/Custom explorers/option-1/styles.css"
```

3. Update the notes.md in option-1 with what changed and why.

4. Update the memory file at `~/.claude/projects/-Users-pratima-rajput/memory/project_action_triggers_prototype.md` with any new changes.
